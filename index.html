Recursos Completos

Poderoso e Flexível

Tudo que você precisa para trabalhar com números por extenso em português

Números Gigantes

Suporte a números de até 10³⁹ (escala curta) ou 10⁷² (escala longa) usando BigInt.

Dialetos do Português

Suporte completo para português do Brasil e de Portugal com diferenças regionais.

Múltiplas Moedas

Suporte a 9 moedas: BRL, EUR, USD, AOA, CVE, XOF, MZN, STN, MOP.

Escalas Curta e Longa

Flexibilidade para usar a escala curta (Brasil) ou longa (Portugal) na escrita dos números.

Altamente Configurável

Personalize gênero gramatical, separadores decimais e formatos de saída.

Zero Dependências

Biblioteca leve e segura, sem dependências externas. Totalmente TypeScript.

Perfeito para aplicações financeiras, educativas e administrativas

Documentos Jurídicos

Contratos, escrituras e documentos formais que exigem valores por extenso.

Comece em segundos

Instale com seu gerenciador de pacotes favorito e comece a converter números em palavras imediatamente

Instalação

$ npm install extenso

Uso Básico

import extenso from 'extenso'

// Número simples
extenso('42')
// => 'quarenta e dois'

// Valor monetário
extenso('1234.56', { mode: 'currency' })
// => 'mil duzentos e trinta e quatro reais e cinquenta e seis centavos'

// Dialeto de Portugal
extenso('16', { locale: 'pt' })
// => 'dezasseis'
